# Property Maintenance Triage Agent

A property-operations agent that categorizes maintenance requests, identifies possible hazards, and recommends routing.

## Workflow

1. Receive the request and available supporting evidence.
2. Classify the issue and apply priority rules.
3. Escalate potential safety hazards.
4. Route the request to property staff or the appropriate trade.

## Passport Files

The root folder contains `agent.yaml`, `SOUL.md`, and `EXPLAINABILITY.md`.
